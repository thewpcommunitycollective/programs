# State of the Community

Documentation and data for the WP Open Community Collective's annual State of the Community Survey.


## About the State of the Community Survey

The State of the Community survey is an annual, anonymous, independent survey of the people who work with, build on, contribute to, or care about the WordPress open source project. The survey asks how they feel about the project, how they are participating in it, and what they want from its future.

The WP Open Community Collective is a member-based organization supporting open source contributors and their communities.

## Not In This Repository

**We are not publishing row-level response data.**

In a  small community, the row-level data could be identifying for some respondents. Anonymity is key to the survey's efficacy.
